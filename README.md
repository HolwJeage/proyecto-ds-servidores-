# Monitoreo Predictivo de Servidores mediante Ciencia de Datos

## Descripción del Proyecto
Proyecto final de Ciencia de Datos enfocado en la infraestructura de TI. El objetivo es predecir estados críticos en servidores utilizando métricas de rendimiento (CPU, RAM, Latencia e I/O de disco).

## Estructura del Proyecto
- **Módulo 1:** Selección del dataset, limpieza de duplicados e imputación de nulos con la mediana.
- **Módulo 2:** Análisis estadístico descriptivo e identificación de dispersión mediante diagramas de caja.
- **Módulo 3:** Modelo de Regresión Logística y visualización de coeficientes e importancia de métricas.
